独立场景根：Patrol routes - 小兵巡逻路径。
七名普通兵分别绑定入口巡哨、中庭侧卫、下院大殿守卫、东书房守卫、观峡山屋巡哨、上院东侧守卫、上院主殿守卫路线。
默认速度约 1.02 米/秒，拐点停 0.5 秒，两端或起点停 1.5～2 秒。原出生位置和朝向保留。

编辑现有路线
1. 在 Hierarchy 选小兵，找到 Samurai Patrol Agent，点击“选择路线”或“定位路线”。也可直接选择上面分组内的路线对象。
2. 路线 Inspector 中选择 Loop（循环）或 PingPong（沿原路往返）。循环会连接最后一点与第一点。
3. 点击“在场景中添加路点”，再点击 Scene 里的可走地面；按 Esc 结束添加。
4. 先开启“编辑路点手柄”，再点击路点编号圆球，用坐标手柄拖动。开启“拖动时贴地”可保持地面高度。
5. 每点可设置停留秒数和停留时的朝向。列表支持插入、删除、上下排序；局部位置也可直接输入。
6. 添加、移动、删除、排序均支持 Unity 的 Ctrl+Z / Ctrl+Y。保存场景后保留路线。
7. “编辑路点手柄”默认关闭，可用普通 Transform 工具移动小兵或整条路线。手动开启后编辑单个路点；按 Esc、切换选择或切换 Play 会退出编辑并恢复普通工具。点击添加路点会自动进入编辑。

为其他小兵创建路线
选中场景里的小兵或它的子骨骼，执行菜单：
Katana > Samurai > Patrol > Create Route For Selected Enemy
它会补 Samurai Patrol Agent，并在独立根下创建路线。已有路线会直接选中，保留手调。
Agent 可调整巡逻开关、路线引用、起始路点（从 0 开始）、行走速度倍率与到达距离。

运行与战斗
按 Play 并捕获游戏鼠标后，小兵开始巡逻；失焦、暂停或原 T 木桩模式会停止自主巡逻。
发现玩家或被玩家攻击后，由原战斗 AI 接管。短暂遮挡保持原追踪规则，超出追踪范围后脱战。
已提交攻击、受击、闪避或击退先完成，再沿本次交战实际走过的位置回到离开路线的位置，接着巡逻。
动态门或其他碰撞挡住返程时，小兵会等待通行。死亡和原 R 复位流程同步清空巡逻进度，恢复出生位姿。
Play 中可以查看当前状态和目标点；路线编辑在 Edit 模式进行，运行进度不保存到玩家存档。

布点注意
相邻点之间应是可直接走过的通道，绕墙和转角处请补点。基础检查按钮可提示墙体、缺地面和陡坡，最后仍需 Play 试走。
默认添加点限制在当前选中点上下 1 米。布楼梯等跨层路线时可暂时关闭限制，并逐段布点；贴地时只在附近高度找地面。
本版采用人工路线与局部碰撞检查，复杂自动绕路可在后续接入导航。
返程轨迹最多保留 256 点。极长追击超过容量后显示轨迹已满并暂停返程，复位后清除。

维护与验证
Katana > Samurai > Patrol > Install Level Patrol Routes
仅在支持关卡的 Edit 模式补缺失路线，已有路线、巡逻开关和参数保留，不自动保存场景。
复测代码：Editor/SamuraiPatrolValidation.cs，须在暂停 Play、timeScale > 0 时执行。
RunMatrix(outputPath)：基础巡逻、真实碰撞、动作中断、脱战返回等。
RunSceneRoutes(outputPath, onlyName)：复制当前路线附近碰撞，在远隔离区试走正式路线。
