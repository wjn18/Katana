薙刀普通连段与空中重击
更新日期：2026-10-19

打开与操作
打开 Scenes/NaginataThirdPersonCombat.unity，进入 Play，并点击 Game 窗口。
WASD / 方向键：相对镜头的八方向移动，角色平滑朝移动方向转身。
Shift：奔跑；默认步行 1.6 米/秒、奔跑 3.2 米/秒。
鼠标移动：环绕视角；俯角限制 15–65 度。
鼠标左键：普通攻击从 01 起手，连续点击按 01→02→04→05→06 衔接；停止点击则当前招式完整收招。
每段最多缓存一次下一段请求，不会把同一点击带到再下一段；不点续招时不会自动播完整套，长按也不会自动连发。
鼠标右键：用户自改 NaginataHeavyAttack03Fix 空中重击，包含角色胶囊的实际离地、滞空和落地。
右键只在空闲时接受；普通攻击或重击进行中点击右键会被忽略，不抢断、不缓存。重击中左键同样忽略。
数字 1–6：单招测试，3 为当前 Fix 重击，其余对应普通招式；数字键触发的单招不接入左键连段。
Esc：释放鼠标并停止接收操控，不是暂停动画；再次左键点击捕获鼠标，该次点击不会攻击。
攻击期间停止普通行走，按方向键可在本招跨步窗口内短促移动；首次实际跨步时转向该方向并锁定到本招结束；视角仍可转动。动作结束后按当前输入恢复移动或待机。
每招第一次真正跨步时，按当时镜头方向与方向键锁定移动方向，并将角色朝向同步转过去；起手时不提前锁定。无方向输入则原地攻击；跨步中松键会急刹，本招内再次按键不重启跨步。
第6招只在首击跨一步，两次挥击保持同一朝向，第二次回斩原地完成；重击仅在下劈附近加入水平跨步，原垂直腾空曲线保持。
同帧多键按左键、右键、数字从小到大的顺序取一个请求；第五段不能缓存下一套普通连段。
普通连段衔接点默认为 01/04 的 60%、02/05 的 62%，续招输入窗口到当前招式的 90%；可在配置中调整。
动作时间轴为60 fps、非循环，默认运行倍率为1。原六招为120 Hz半帧烘焙；Fix保留用户非均匀关键时序，以更密FBX采样原样导出。
普通 01/02/04/05/06 的完整片段时长为 1.35/1.416667/1.216667/1.266667/1.616667 秒。
当前Fix重击为2.75秒，0–1.40秒与旧2.25秒Heavy03保持一致；起跳0.22秒、顶点1.275秒、落稳1.50秒，后段按用户时间调整回守至2.75秒。跳高与姿态沿用用户源；旧Heavy03和原1.80秒第三招的来源资料保留，当前Unity独立片段与状态以“交付与来源”所列为准。

代码职责
Runtime/Input/CombatInputSource.cs：输入抽象；控制器只依赖操作意图，可替换为 AI 或回放输入。
Runtime/Input/CombatInputFrame.cs：不可变单帧快照，默认值不会触发攻击。
Runtime/Input/CombatPlayerInput.cs：Input System 适配、私有动作实例、按下边沿和焦点/鼠标生命周期。
Runtime/CombatActorController.cs：组合入口；固定顺序协调输入、攻击、运动与动画，绑定场景相机。
Runtime/CombatCharacterMotor.cs：CharacterController 位移、水平转向、加减速、重力、攻击跨步与基于重击进度的真实离地运动。
Runtime/CombatAnimationDriver.cs：唯一 Animator 写入入口、五段顺序与一次续招缓存；以当前/目标动画实际进度协调跨步、重击高度和伤害窗口开关。
Runtime/CombatMovementSettings.cs / CombatAttackDefinition.cs：只存配置，不存每个角色的运行状态。
Runtime/Camera/CombatOrbitCamera.cs：独立相机，接收 Look 意图并在 LateUpdate 平滑跟随玩家容器。
Runtime/CombatControlsOverlay.cs：可单独移除的演示操作提示。
Runtime/OCDesign.Combat.asmdef：独立运行程序集，仅依赖 Unity 与 Input System，不依赖旧预览脚本。
各组件包含中文 XML 摘要、关键逻辑注释和 Inspector 参数说明。

跨步与预留伤害窗口
配置保存在当前6个CombatAttackDefinition（01、02、Heavy03Fix、04、05、06）。stepSpeed横轴是本招归一化动画时间，纵轴是目标速度（米/秒）；起步为平方增长，出招段维持较高速度，末段急减至0。加速度为18＋目标速度×10米/秒²，普通制动90米/秒²，重击制动130米/秒²；窗口结束后水平速度归零。
damageWindows为Vector2[]，每项x/y是归一化开始/结束时间；06有两个分离窗口，中间不开放判定。下表为运行倍率1时对应的秒数，峰值是配置目标速度，不是实测距离或碰撞后的速度。

02          0.36–0.52                 0.28 / 0.40 / 0.59         4.0
04          0.27–0.44                 0.20 / 0.31 / 0.51         3.8

01/02/04/05的配置窗口结束安排在各自下一段衔接点之前；06作为最后一招，回斩保留第二伤害窗口但没有第二次跨步。
目前只提供窗口查询和开关事件，没有敌人、命中碰撞或扣血实现。CombatAnimationDriver.IsDamageWindowActive表示当前是否开放，ActiveDamageWindowIndex表示窗口索引（关闭后为-1），DamageWindowChanged(attack, serial, bool)通知对应攻击和出招序号的开关。
后续伤害模块可用CombatAttackDefinition.GetDamageWindow(index)读取时间范围，以Driver.AttackSerial区分每次出招，并自行记录命中目标去重；需要06两段分别命中时可再结合窗口索引。现阶段不在Driver或Motor内施加伤害。

后续扩展
调手感：编辑NaginataMovement的速度/加减速/转速，编辑相机的距离/灵敏度/跟随时间。
改按键：编辑 CombatControls.inputactions，保持 Gameplay 与现有 Action 名称即可。
替换招式：给新的非循环动画建 Animator 状态；在对应攻击资产填完整状态路径和速度。
调连段：普通配置的 Combo Link Normalized 为最早衔接点，Combo Input Close Normalized 为最后续招输入时刻。
调重击：airborneHeight 横轴为归一化动画时间、纵轴为玩家胶囊离地米数；曲线首尾保持零高度。
当前数组固定为六项，顺序 01、02、重击03、04、05、06；若增加新招，需同步驱动器顺序/验证和输入映射。
接入 AI：继承 CombatInputSource，返回移动/攻击意图，调用 actor.Configure 注入。
新场景：放入角色 Prefab 与带 CombatOrbitCamera 的 Camera；调用 BindCamera 或在 Inspector 绑定。
  只有未显式绑定时才在 Start 查询一次 Camera.main；不要把相机挂成角色的子对象。
新增伤害系统时使用独立战斗模块管理命中窗口和伤害，避免塞进输入或 CharacterMotor。
当前 Animator 参数约定：MoveSpeed(float，0/1/2 对应 Idle/Walk/Run)、AttackSpeed(float)。
当前状态路径：Base Layer.Locomotion、Base Layer.NaginataAttack01/02/04/05/06、Base Layer.NaginataHeavyAttack03Fix；旧失效Base Layer.NaginataHeavyAttack03状态已在此前目录整理时清理。
输入 Attack01–Attack06 对应单招测试数组 0–5；PrimaryAttack 输出起手/续招意图，SecondaryAttack 仅输出重击意图。
状态间由 AnimationDriver 单一管理，不依赖动画事件或另一套自动过渡条件。

当前范围与限制
实现方向移动、奔跑、第三人称镜头、五段普通连段、攻击跨步和空中重击，预留伤害窗口查询/事件；没有敌人、命中碰撞、扣血、锁定或闪避。
CharacterController 有基础重力、碰撞和重击起跳；没有独立自由跳跃、移动平台、复杂地形贴合或相机避障。
演示场地用于平地验证。镜头跟随角色容器，不跟随翻转攻击的髋部，以保持视角稳定。
Root Motion关闭；攻击跨步通过CharacterController.Move推进玩家容器，重击同时按独立高度曲线改变世界高度。
高度跟随动画实际进度，顶碰后停止上升并恢复重力；重击中断时以重力落地，不瞬移到地面。
空中骨骼姿态与容器高度同时作用于最终画面，需结合当前主角检查腾空和落斩效果。
原衣物/逐指/握持辅助的限制仍在，视觉检查不代表所有动作和视角完全无穿模。
镜头沿用既有默认 16:9 配置；极窄纵横比或新增障碍需要再调镜头。
默认输入面向单个本地键鼠玩家；手柄、多玩家与运行时重绑 UI 尚未实现。

重击落地反馈（2026-10-19）
Heavy03Fix在落地前6帧开始向前传播黑色地裂，少量灰褐低尘沿裂纹顺序冒出；按数字3或右键查看。此效果替代此前的青白冲击圆环。
CombatLandingImpact仅在重击下降阶段只读预测未来0.10秒的接地，确认地面后提前6帧（按60 fps为0.10秒）同时启动地裂与低尘，每次重击仅一次。提前发射时将角色前向和世界落点锁定到预测地面；实际接地只补记、不重复触发，也不重新锁定落点或方向。裂纹向前逐段显露、短暂残留后淡出，不随玩家移动或转向漂移。外观与尺寸、传播和消退参数保持，以当前组件和外部任务说明为准。
中断、Animator或组件禁用、切换出招会清空效果，普通五招不触发。预测只读查询未来接地与地面，不推进或改写Motor运动、胶囊位置和动画；LastCollisionFlags继续用于实际碰撞观测。
菜单OC Design > Combat > Install Heavy Landing Impact可定向装配。继续使用独立组件、两材质与VFX/Shaders/GroundImpact.shader；VFX/HeavyLandingRing.mat已移动更名为VFX/HeavyLandingFracture.mat，保持GUID并使用Mode 2，VFX/HeavyLandingDust.mat负责低尘。
本轮动画、控制器、武器挂点、移动和六招刀光保持。地裂为贴近地面的片状视觉网格，不修改地形、不产生物理裂口，当前适用于平地；复杂台阶、边缘和地形贴合需另行适配。
当前工具、说明与记录见外部斗笠剑士/动画资源/naginata-ground-fracture/；图片预览在同角色图片资源/模型预览/naginata-ground-fracture/。naginata-heavy-impact/及其同名图片目录保留已被替代圆环的历史资料与回退，非当前效果。六招刀光资料继续使用naginata-vfx/。
